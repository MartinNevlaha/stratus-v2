# Bug workflow

Use Superpowers systematic debugging before proposing a fix. Register `type: bug`, a unique `bug-...` ID, a title, and the current native session ID. Follow analyze → fix → review → complete; a failed review returns review → fix. Reproduce the defect, watch the regression test fail, implement the smallest fix, then run the relevant checks. Record actual tasks and results; do not mark completion merely because an agent stopped.
