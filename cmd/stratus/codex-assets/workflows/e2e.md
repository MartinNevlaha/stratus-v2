# E2E workflow

Register `type: e2e`, a unique `e2e-...` ID, a title, and the current native session ID. Follow setup → plan → generate → heal → complete, with heal → generate for additional corrections. Use native browser capabilities to inspect real UI behavior; do not assume a Playwright MCP or Claude-specific test agent is installed. Keep verification evidence and task outcomes in the workflow. The status dashboard and the application under test are separate pages.
