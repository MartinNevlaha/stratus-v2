# Feature workflow

Follow the approved Superpowers design and implementation plan. Register `type: spec`, a unique `spec-...` ID, title, current native session ID, and `complexity: simple` or `complex`.

A simple workflow remains in plan until the implementation plan is approved, then follows plan → implement → verify → learn → complete. A complex workflow uses plan → discovery → design → governance → plan, then follows implement → verify → learn → complete after approval. Store approved plan/design content through the available tools. Keep ordered tasks and explicit completion updates in Stratus. On failed review return verify → implement and fix the findings. Do not change the server's phase graph or treat hook success as approval.
